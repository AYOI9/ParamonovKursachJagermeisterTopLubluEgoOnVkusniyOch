## Функциональные возможности
- **Гостевой режим:** просмотр каталога товаров и регистрация нового клиента.
- **Кабинет клиента:**
  - авторизация в системе;
  - просмотр и поиск товаров в каталоге по названию и категории;
  - формирование корзины с проверкой остатков на складе;
  - оформление и оплата заказов (банковская карта / электронный кошелек);
  - просмотр истории заказов;
  - автоматическая блокировка оформления новых заказов для клиентов, занесенных в «черный список».
- **Панель администратора:**
  - ведение каталога товаров (добавление, редактирование, удаление);
  - просмотр всех заказов и отбор неоплаченных / просроченных заказов;
  - занесение неплательщиков в «черный список» с указанием причины и снятие блокировки.

## Структура проекта
- `OnlineStoreApp/` — основное консольное приложение C# (`Models/`, `Services/`, `Program.cs`)
- `OnlineStoreApp.Tests/` — автоматизированные тесты бизнес-логики (21 тест)
- `Diagrams/` — UML-диаграммы и макеты интерфейсов в форматах Visio (`.vsdx`) и `.png`
- `Screenshots/` — снимки экрана работы программы и истории коммитов Git

## Запуск и тестирование
```bash
dotnet build OnlineStoreApp/OnlineStoreApp.csproj
dotnet run --project OnlineStoreApp/OnlineStoreApp.csproj
dotnet run --project OnlineStoreApp.Tests/OnlineStoreApp.Tests.csproj
```
